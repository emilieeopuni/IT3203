About This Project

This website was created for IT 3203: Web and Internet. It builds on my research about the Domain Name System and this project presents the information as connected web pages.

The goal of this project is to explain how DNS works, introduce concepts surrounding it, describe its history, and the security challenges and break it down in a more simpler way that beginners or non-experts can understand.

This website is a class project for IT 3203: Web and Internet at Kennesaw State University.
