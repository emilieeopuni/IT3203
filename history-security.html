The History of DNS

Before DNS, computers on the early internet relied on the shared file called HOSTS.TXT to match computer names with IP addresses. Eventually the network grew, and maintaining and distributing this file became difficult.

In 1983, Paul Mockapetris introduced the "Domain Name System". DNS organizes names into a hierarchy and distributes responsibility across servers; allowing for the naming system to grow with the internet.

In 1987, RFC 1034 and RFC 1035 documented the core DNS concepts and implementation. These documents remain the foundation of how DNS operates.

DNS Security Threats

  • Cache poisoning: False DNS information is stored in a resolver's cache, potentially directing users to a malicious website.
  • DNS hijacking: Attackers change DNS settings or records to redirect users without permission.
  • Denial-of-service attacks: Attackers overwhelm DNS infrastructure with traffic, overwhelming services and making them difficult to reach.

Protecting DNS

DNS Security Extensions (DNSSEC) use digital signatures to help validating resolvers verify the origin and integrity of DNS data.

DNS over HTTPS (DoH) and DNS over TLS (DoT) encrypt queries between a client and a supporting resolver. This helps protect those queries from being read or modified while it travels between them.

Strong passwords, multifactor authentication, software updates, and monitoring help protect DNS management accounts and servers.
