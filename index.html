What Is DNS?

The Domain Name System (DNS) turns/translates domain names into IP addresses that computers can use to locate services on a network. Instead of people having to memorize numberical addresses, DNS allows people to use memorable names.

About This Website

This website introduces how DNS works, the history, and the security challenges. Explore the pages to learn how DNS ties together domain names and IP addresses to support everyday internet use.

Key Terms

  • IP address: An address used to identify a device or network interface.
  • DNS resolver: A service that helps finds DNS answers for a client.
  • Caching: Temporarily stores DNS answers for reuse.
  • Domain name: A readable name, such as example.com, used to identify an internet resource.
